# RechnungApp

Rechnungssystem für die eigenen Kunden – Schwester-App von **MyDesk** (gleiche Technik, gleiches Design, eigene Daten).
Am Handy erfassen (Foto, Texterkennung, Sprache), am Laptop oder Handy daraus rechtssichere Rechnungen erstellen –
zum Mailen und zum Drucken.

**Stand:** Planung, noch kein Code. Der vollständige Fahrplan – Funktionsumfang, Rechtslage (Stand Oktober 2026),
Technik, Etappen, Voraussetzungen und offene Fragen – steht in [FAHRPLAN.md](FAHRPLAN.md).
